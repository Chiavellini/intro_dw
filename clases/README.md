Que son las clases?
-son "moldes" para crear objetos. Dichos objetos tienen propiedades y metodos.

Como se crean instancias?
-se crean con new: let p1= new perro("Mao", doberman)

Metodos y funciones?
-se definen directamente dentro de la clase, sin usar la palabra "function"
-Le aplicas metodos a un objeto dada la funcionalidad que cumpla el objeto.
-los metodos estaticos pertenecen a la clase, no a las instancias. Son metodos que daran el mismo resultado a todas las instancias de una clase sin importar las diferencias entre si.
