.toEqual()
-Compara valores y estructuras internas de objetos/arrays.
No requiere que sean el mismo objeto, solo que tengan el mismo contenido.

.toBeTruthy()
-Pasa si el valor evaluado en un booleano es true.

.toBeFalsy()
-Pasa si valor evaluado en booleano es false.

.toBeNull()
-Pasa si valor evaluado es null

.toBeUndefined()
-Pasa valor es undefined

.toThrow()
-Sirve para probar que una función lanza (throw) un error.

.toStrictEqual()
-Parecido a .toEqual(), pero más estricto.
